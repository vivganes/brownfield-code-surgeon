# Privacy Policy

**Effective Date:** April 25, 2026

## Overview

This privacy policy describes how the Brownfield Code Surgeon plugin handles user data and privacy. We are committed to protecting your privacy and being transparent about our data practices.

## Data Collection

**We do not collect any data from the plugin.**

The Brownfield Code Surgeon plugin:
- Does not track usage statistics
- Does not collect user information
- Does not send any data to external servers
- Does not monitor code content or user activity
- Does not store personal or project information

## How the Plugin Works

The plugin operates entirely on your local machine:
- All processing happens locally within your development environment
- No information is transmitted to external services (except as required by APIs you explicitly authorize, such as Claude API calls)
- Your code and project files remain completely within your control

## Third-Party Services

If you use this plugin with the Claude API or other third-party services, those services have their own privacy policies. Please refer to the respective privacy policies of those services for information about how they handle data:
- **Anthropic Claude API**: https://www.anthropic.com/privacy
- Any other external services you choose to integrate with

## Contact

If you have any questions about this privacy policy or our data practices, please contact us by raising an issue at the project repository.

## Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected in the effective date shown above.
